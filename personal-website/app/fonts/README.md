# Self-hosted typefaces

Original Google Fonts distributions, retrieved 2026-10-27 from fonts.gstatic.com.
Inter (100–900) and Cormorant Garamond (500–700) use Latin WOFF2 subsets.
Amiri regular/bold use full TTF files to preserve Arabic and Latin coverage.
The accompanying SIL Open Font Licenses are retained without modification.
Self-hosting preserves the existing typography and removes build-time Google
Fonts requests; fonts are served with the application through next/font/local.
