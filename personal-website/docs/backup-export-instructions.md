# Backup and Export Instructions

## Database

Export Supabase PostgreSQL backups from the Supabase dashboard or CLI before major releases.

Recommended tables to back up frequently:

- users
- products
- courses
- lessons
- orders
- memberships
- articles
- inquiries
- bookings
- certificates
- downloads
- newsletter_subscribers

## Files

Back up:

- Product files
- Course videos and materials
- Certificates
- Press assets
- Profile PDFs
- Agro profile documents

Use Supabase Storage or Cloudinary export tooling depending on the final storage provider.
