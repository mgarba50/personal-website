# Owner Handoff Notes

## What is ready now

- Institutional public pages across the main corridors
- Typed content architecture
- Search and discovery foundation
- Multi-path contact and intake structure
- Transactional email readiness through Resend-compatible logic
- Payment readiness surface for international, regional, and manual rails
- SEO foundation and policy scaffolding
- PowerShell automation package

## What still needs real owner data

- Final biography and verified milestones
- Official portrait and press assets
- Real books, essays, and poetic catalog data
- Real policy/legal copy
- Payment gateway credentials
- Email sender/domain configuration
- Optional analytics and monitoring IDs

## Owner routine tasks

- Add or update content in `content/collections/*.ts`
- Replace or add assets in `public/assets/`
- Run `.\scripts\content-check.ps1`
- Run `.\scripts\validate-assets.ps1`
- Run `.\scripts\build-production.ps1`

## Launch discipline

- Do not publish placeholder policy language
- Do not publish placeholder press assets without approved replacements
- Do not enable live payment buttons until provider keys and webhooks are configured
- Do not expose premium or protected areas until auth and storage policy are finalized
