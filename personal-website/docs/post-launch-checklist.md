# Post-Launch Checklist

- Confirm all production environment variables.
- Run a test Stripe payment.
- Run a test Paystack or Flutterwave payment.
- Submit a manual payment proof and verify admin handling.
- Test digital product delivery.
- Enroll in a course and verify dashboard access.
- Submit contact, advisory, media, and agro inquiry forms.
- Verify newsletter welcome email.
- Review legal pages with qualified counsel.
- Enable Supabase Row Level Security.
- Connect analytics and conversion tracking.
- Submit sitemap to Google Search Console.
- Confirm mobile performance and image loading.
